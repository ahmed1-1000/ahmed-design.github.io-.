About soun

soun is a modern 3D-first website template designed to showcase immersive scenes and interactive experiences. It uses a modular scene system built on top of Three.js to render dynamic backgrounds, while keeping clean, accessible HTML content for marketing copy and UI controls.

Features

  • Multiple 3D background themes with smooth transitions
  • Mouse, touch and device orientation interaction
  • Lightweight rendering with progressive enhancement
  • Contents overlay with accessible navigation
  • Easy to customize and extend with GLTF assets
